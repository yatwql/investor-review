# 持仓成本相对历史价格区间位置（cost_position）设计 —— plan-90

> **状态**：设计（plan-90 落地设计；仅维护持仓表，流水类指标不纳入范围）。
> **输入**：仅持仓表（名称/代码/份额/每份成本）+ 既有行情缓存。不接券商、
> 不需交易流水、不新增数据源。

## 1. 问题重述

持仓表仅 4 列，`每份成本` 相对历史价格区间的位置（成本买在区间高位 ≈ 追涨、
低位 ≈ 低位布局）在报告中无任何呈现，用户只能拿成本价与现价逐格对比人工判断。
本设计给出一个**零额外输入**的近似指标填补该空缺。

## 2. 指标定义

对每个持仓品种，取其历史行情的两个时间窗口（近 20 交易日、近 52 周）：

```
cost_position_pct = clamp((cost - low) / (high - low), 0, 1)
```

- `cost`：持仓表「每份成本」；`low`/`high`：窗口内最低/最高成交价
- 语义：≈1 → 成本买在区间高位（追涨嫌疑）；≈0 → 低位布局
- `high == low`（停牌/极窄波动）→ 取 0.5 中性值
- `cost` 越出区间（大幅浮盈/浮亏后加仓摊薄等）→ clamp 到 0/1 并可标注越界

窗口参数（20 日 / 52 周）为默认档，实施时可依据呈现效果微调，但须在呈现处
注明实际窗口。

## 3. 数据来源与降级

- **行情**：复用既有 fetcher + `data/cache/` 缓存（TTL 既有规则），不新增数据源
- **降级链**：缓存命中 → 现网拉取 → 缺失留空（呈现为「—」+ Data States 口径
  空态文案）；行情不可用时整块降级，不阻塞报告生成
- 遵循概要设计数据降级治理体系（technical.md §1.4.5），不新造降级通道
- 场外基金等无日频行情品种：天然走缺失留空路径，无需特判

## 4. 呈现位置（候选，实施时定夺）

- **方案 A（主推）**：持仓明细页签新增「成本区间位置」列（两窗口百分位并列）
- **方案 B（汇总）**：量化指标页签聚合块——如「高位追涨嫌疑品种清单」
  （近 20 日位置 ≥0.8 的品种）供行动建议引用
- 建议先 A 后 B；HTML 报告是否同步呈现视 Excel 试点效果再定

## 5. 口径注记（必须随呈现展示）

- `每份成本` 是持仓均价，**无法区分一次性买入与分批定投**——指标是买入时机的
  近似而非精确回放，呈现处须注明
- 窗口参数与百分位公式须在页签说明/表头注释中写明，避免裸数字误读

## 6. 边界

- 不做持有期分布 / 处置效应 / 调仓频率等依赖交易流水的指标（无流水输入，
  不纳入范围）
- 不做「开户/定投交互式对话」（交互形态，不在范围）
- 不做券商对接 / 交割单导入（暂缓；若未来引入流水再评估行为类指标）

## 7. 测试要点

- 单元：百分位计算边界（`high == low`、`cost` 越界 clamp、空窗口）
- 降级：行情缺失留空不抛错、不阻塞管线（edge 场景入 `*_edge.py` +
  `@pytest.mark.edge`）
- 真值单一来源：窗口参数等从常量/配置派生，不写死派生量
