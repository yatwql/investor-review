# DESIGN-TUI.md — 投资复盘助手终端交互契约

> **适用对象**：`src/python/tui/` 下一切交互改动——提示语、键位、面板版式、反馈与空态文案。
> **定位**：TUI 侧**唯一判据**，与 [`DESIGN.md`](DESIGN.md)（Web/报告视觉契约）对称：一个守「看什么」，一个守「怎么按、按了会怎样」。
> **守卫**：`src/test/unit/ui/test_design_tui_doc.py`（骨架 / 键表 / 表格列 / 口径句 / 护栏 / 术语表 / 闸门白名单交叉校验） + `src/test/unit/ui/test_prompt_contract.py`（上屏提示成分、禁用词、闸门白名单机检）。
> **设计依据**：TUI 人机工程治理设计（HCI 原则对照、措施分批与验收载体）——该设计稿已随 v0.13.x 治理批次完成并归档，本契约为其定稿判据。

## Overview — 基调与哲学

TUI 的第一用户是**在手机上用 SSH 看持仓的人**，不是写代码的人。因此：

| # | 原则 | 判据 |
|---|---|---|
| P1 | **识别优于回忆** | 数字编号是第一入口；字母只作别名；任何键都必须能在屏幕上看到说明 |
| P2 | **一键一义** | 同一按键全局只有一个含义；冲突时改语义，不改文案去圆 |
| P3 | **屏幕自解释** | 不翻手册即可走完主路径；`?` 在任何面板都能问到帮助 |
| P4 | **专家快路不牺牲可发现性** | 直达键/键名/组合输入保留，但必须出现在页脚或 `?` 帮助里 |
| P5 | **可机检优先** | 每条纪律都要有守护载体，不靠口头纪律 |

## Keys — 键分工总表

| 键 | 唯一语义 | 禁止用法 |
|---|---|---|
| 数字 `1..N` | 选择项（**第一入口**，编号连续无断层） | 不得跳号；不得与字母混用表达同一动作 |
| 子项编号 `7.1` | 某章节下的生成选项（十进制子编号；父章节编号保持稳定） | 不占章节编号、不单列返回项；父项关闭时名称/键名置灰并提示原因，状态字仍保持红色「关」 |
| 回车 | 执行**本行提示标注的默认项** | 不得表达「取消」；不得作为"无标注的默认"（必须写明默认项是什么）；屏幕上不得写作英文 `Enter`（同键两名会让人以为是两个键） |
| `?` | 帮助：无参=当前屏可用键一览（首页给菜单键 + 分组索引 + 三条常用动线）；`?N`=第 N 项详情 | 不得仅个别面板支持；首页不得缺此入口 |
| `0` | 返回上一层（首页即退出） | 不得在部分面板改为「返回上上层的上一项」 |
| `Esc` | 取消当前提示 / 返回上一层 | 不得直接退出程序（退出走 `0` / `X`） |
| 字母 `A-Z` | 直达别名（专家快路） | 不得成为唯一入口；不得只存在于代码而不上屏 |
| `u` / `U` | 配置面板内：`u` 退回最近一次改动、`U` 还原到进入本面板时（改动仍即时生效，退回靠变更前值，不靠草稿） | 不得出现在非配置面板；页脚须显示「本次改动 N 项」事实行（无改动时不出现） |
| `/` | 主菜单关键词筛选（标签子串 / 按键精确命中；空回车清除） | 不得隐藏编号与字母（筛选只缩小范围，不改键义） |
| `↑` `↓` `Enter` | 面板内移动选中 / 执行选中（`j` / `k` 为 `↓` / `↑` 的同义别名） | 分档只改版式不改语义（约束 C29）；面板已占用两字母时须显式关掉别名（`panel_loop(nav_keys=False)`，目前仅 `[S]` 的 `k` 切键名列） |
| 分页视图内：`空格`/`↓`/`j` 下翻 · `↑`/`k`/`b` 上翻 · `g`/`G` 首末 · `/` 搜索 · `q`/`Esc`/`0` 退出 | 只在 `pager.view` 的浏览视图内有效（一屏 + 页脚键位行） | 不得泄漏到主菜单或面板；不足一屏 / 非 TTY 时整段直打，不读键 |

## Prompts — 提示三段式模板

```
  <动作指令>（如 3）· <默认项声明> · ? 看说明 · 0 返回:
```

| 成分 | 要求 | 反例 |
|---|---|---|
| 动作指令 | 动词 + **一个具体示例** | 「请输入编号」 |
| 默认项声明 | 回车会做什么，写明动作名 | 「回车=确定」 |
| 帮助入口 | `? 看说明`（或 `?3 查看说明` 形态） | 只字不提帮助 |
| 返回键 | `0 返回` | 裸提示 `缓存管理> ` |
| 折行 | 超宽走 `wrap_prompt` / `wrap_hanging`（窄屏基准 40 列） | 长提示硬折导致光标脱节 |
| 面板输出 | **所有**上屏行（提示语之外，含表格/统计/日志/盒线面板）在 40 列下不得超宽：盒线面板用 `switch_panel.render_titled_panel`（宽/中档画框、窄档无框截断），长文本用 `wrap_hanging`、单行用 `truncate_display` | 无条件 `render_panel`（宽度内容驱动，窄屏撑出 49~57 列被终端硬折成锯齿） |

**禁止形态**：裸提示（无返回键）、只列按键字母（`(A/D/R/0)`）、纯占位符描述（`? 编号 看说明`）。

## Defaults — 默认项与取消标注语法

| 场景 | 写法 | 禁止写法 |
|---|---|---|
| 回车执行默认 | `回车=用缓存生成`（写明动作名） | `回车=确定` |
| 需要取消 | 用 `0` / `Esc`；确需回车取消时写 `回车=取消` 且置于句首 | 括注里藏「直接回车取消」 |
| 二选一确认 | `(y/N)`——大写一侧为默认 | 大小写混用、无默认暗示 |
| 危险操作 | 默认项必须是**安全侧**（中止/不覆盖） | 默认写盘、默认覆盖 |

## Colors — 配色角色（一色一职责）

多色可以，但每个颜色只承担一个职责；取值与 `src/python/core/ansi_colors.py` 同源，**非 TTY / `NO_COLOR` 下全部退化为无色**——文本本身仍可读，语义不依赖颜色。

| 角色 | 取值 | 用在哪 | 不得用在 |
|---|---|---|---|
| 品牌 | 橙 + 粗体 | 首页应用名与版本号 | 正文与状态值 |
| 结构 | 蓝 + 粗体 | 分组标题（首页四组、`[C]` 四块、`[S]` 五组、`[G]` 四组）、面板横幅 | 状态值与键位 |
| 焦点 | 青 | 当前选中标记（首页 `>`、面板行首游标） | 未选中行 |
| 状态 | 绿 / 黄 / 红 | 正常 / 需要注意（数据偏旧、数据源失败、LLM 未配置） / 错误 | 整段正文 |
| 事件（LLM 调用） | 品红 | 报告运行期**真实 LLM API 调用**的日志行（`[LLM]` 前缀：调用开始与每次用量），控制台与 `[D]→[V]` 查看器同款 | 预检/跳过/缓存命中或禁用等「没调用」的行、状态值与正文 |
| 弱化 | DIM | 分隔线、页脚图例、动作提示行的 `└` 标记 | 关键操作说明、动作正文 |

**状态色不被置灰吞掉**：关闭项的状态字恒为红色、开启项恒为绿色；`DIM` 只作用于名称/键名/附注，不得包裹整行或状态字（否则父项关闭时「关」会退化成无色）。

**LLM 调用行凭前缀认色**：实际 API 调用的日志文案必须以 `[LLM]` 开头（唯一判据在 `core/logger.is_llm_call_message`），控制台格式器与 `[V]` 查看器据此上品红；`[LLM 预检]`、`LLM 缓存命中`、`已禁用` 等判定/跳过行**不得**借这个前缀——颜色只承诺「这里真的花钱调用了」。级别色优先：`[LLM]` 行若同时是 WARNING/ERROR，仍按状态色显示。

**先排版后上色**：折行与截断必须在着色前完成；结构色统一经 `src/python/tui/text_layout.py` 的 `style_heading` 产出；其余角色色按上表就地包裹，不自造新色。

**分组标题全局同款**：任何渠道的分组标题（首页主菜单四组、`[C]` 四块、`[S]` 五组、`[G]` 四组，以及今后新增的面板分组）一律经 `text_layout.group_heading()` 产出——形态固定为 `── 组名 ──`、结构色（蓝 + 粗）、按给定列宽折行。渠道**不得**自造分隔符、裸色组名或另写缩进；面板内调用时把折行预算传面板内宽（`inner_width(columns)`），保证窄屏不撑破右边框。组间以空行分隔，组内条目紧随组标题。

## Display Modes — 行型与状态（配置项 / 分组 / 提示 / 开关）

所有面板共用四类行型；新增面板只能组合这四类，不得就地发明第五种排版或颜色语义。

| 行型 | 形态 | 颜色 | 唯一产出点 |
|:--|:--|:--|:--|
| 分组标题 | `── 组名（n/m 开）──`，组间空行 | 蓝 + 粗（结构色）；**分组描述本身也是蓝色**，不承载状态 | `text_layout.group_heading()` / `switch_panel.format_heading()` |
| 配置项 | `编号. 名称  键名 [状态]*`；键名恒显，窄档第二行 | 名称正文色、键名 `DIM`、状态按开关语义；整行不整体着色 | `switch_panel.format_item()` / `[C]` 的 `_format_row()` |
| 开关状态 | 宽/中档 `[开启]` / `[关闭]`，窄档 `[开]` / `[关]` | 开启绿、**关闭恒红**；**状态字不被置灰吞掉**——不得因父项关闭或整行置灰而退化为无色 | `switch_panel.status_text()`（唯一实现，`[C]` 也复用它） |
| 提示/反馈 | `  > ` 输入位；`[OK]` / `[!]` / `[ERR]` 反馈 | 成功绿、告警黄、错误红；正文提示不加状态色 | `prompt_text.panel_prompt()` / `wrap_prompt` / `tui_menu` 反馈常量 |

补充规则：

- **父项关闭的子项**：名称与键名置 `DIM`，状态字仍按「有效状态」显示红色 `[关闭]`，行尾附「启用本章节后可切换」；不得只置灰不给状态。
- **`*` 标记**：只表示「当前值与出厂默认不同」，不改变状态色；`[开]*` 是开启且偏离默认，不是异常。
- **整行着色禁止**：`DIM` 只能包名称/键名/附注，不能包状态字或整行；状态字着色后必须 `RESET`。
- **截断安全**：任何折行/截断前先算显示宽度；截断含 ANSI 的行必须补齐完整转义并以 `RESET` 收尾（`text_layout.truncate_display` 已内置），否则颜色会泄漏到下一行。
- **分组标题不得手写**：不得在业务面板里拼 `"── ... ──"` 裸串或自行套 `BLUE`；统一走上表产出点，保证 `[C]` / `[S]` / `[G]` / 首页四组同款。

机检载体：`src/test/unit/ui/test_text_layout.py`（ANSI 截断闭合）、`src/test/unit/handlers/test_handlers_report_chapters.py`（关闭状态红色/父项关闭）、`src/test/unit/ui/test_prompt_contract.py`（提示与禁用词）。

## Vocabulary — 术语对照表

| 内部词（禁止上屏） | 用户词（上屏） |
|---|---|
| 强刷 / force | 重新生成（会调用 AI，计费） |
| 走缓存 / cache hit | 用已有结果（免费，可能不是最新） |
| 降级 | 改用备用方案（结果可能略旧） |
| 分档 / tier / 窄档 / 宽档 | 不上屏（版面差异用户无需知道名称） |
| 游标 / cursor | 选中项 |
| 配置漂移 | 与出厂默认不一致 |
| 熔断 / 退避 | 暂时失败，稍后自动重试 |
| `Enter`（按键英文名） | 回车 |

**适用范围（写在表后，避免两种口径互相误伤）**：

| 场景 | 口径 |
|---|---|
| TUI 提示行 / 反馈行 / 状态标签（含页头状态行、LLM 状态面板） | 本表用户词（`数据源失败` / `自动重试: 正常·暂时失败`） |
| Web 工作台、CLI 终端的**状态表与决策屏** | 与 TUI 同词——端点状态经 `core.system_info.circuit_display` 唯一归一，预算确认统一说「用已有结果继续」，三渠道不得各自命名同一决策 |
| 报告 / Web 的**数据降级**呈现（源失败占位、降级明细） | 沿用 [`DESIGN.md` Data States](DESIGN.md)：此处的「降级」指数据质量，不是端点重试状态 |
| 日志、代码注释、FAQ / 机制文档 | 保留技术词（熔断、退避、强刷）——排障与检索需要精确术语；`[V]` 日志详情同此口径 |

## Feedback — 反馈与空态口径

| 场景 | 前缀 | 要求 |
|---|---|---|
| 进行中 | `[..]` | 具体动作 + 进度（「正在获取行情（3/12）」优于「处理中」） |
| 长任务状态条 | 无前缀单行 | 报告生成期间的当前阶段：`[..] 「阶段」· 已 12s · 约剩 40s · q 中止`，**原地覆写同一行**；落地行（`[OK]`/`[!]`/`[ERR]`）打印前先清条、打印后重画；只在 TTY 上出现，非 TTY / `TUI_PLAIN` 退回逐行 `[..]`；`q` 为**有序中止**（下一阶段边界生效，已完成产物与缓存保留），键不可用时尾部改显 `Ctrl+C 中断` |
| 成功 | `[OK]` | 带可核对的量（数量/路径/金额） |
| 部分失败 | `[!]` | 哪部分失败 + 影响 + 怎么办 |
| 错误 | `[ERR]` | 原因 + 下一步动作（不得只给异常类名）；动作短语与页头同源（`tui/action_hints`，经 `error_tail.emit_error` 拼为 `原因 → [D]→L 看运行日志`），就地纠正类输入校验（应为/必须/不能/无效）除外；宽屏与窄屏同一折行口径 |
| 空态 | `[!]` | 说清「为什么没有」+「怎么才会有」 |
| 面板按键反馈 | 无前缀单行 | 一次按键必有可观察结果（C29 两档同语义） |
| 页头状态行 | 无前缀 | 两项条约：**首行只报事实**——四项常驻（上次报告/新鲜度/数据源失败/LLM，顺序与 `[M]` 面板编号同一口径（`config/_llm_providers.order_providers_by_chain`））+ 条件出现项 `缓存过期 N`（**仅 N>0 时上屏**：启动已自动清理，常态 0 只会引人发问），LLM 段 = 状态点 + 多链链首线路名，上屏段不折行；**需要动作才给提示**——异常段自带一句动作短语（`[3] 清理过期缓存` / `[2] 更新行情缓存` / `[D]→V 看数据源记录` / `[G]→L 配置 LLM`），汇总为第二行 `└ …` 缩进提示（按列宽折行，不丢菜单键）；全部正常时**无第二行**——不向「一切正常」喊话。短语单源在 `status_line.ACTION_TEMPLATES`，首键必须是主菜单顶层键，由 `test_tui_menu_status.TestActionHintKeys` 对主菜单键做子集校验（菜单改键即红） |；**首用未就绪项只占一行**（`📋 未就绪：持仓文件 · LLM（[G] 配置 · ? 看指引）`），详细引导进首页 `?`，就绪后整行消失

### 按键闸门白名单（`按任意键返回菜单`）

查看类长输出已改走**分页视图**（`pager.view`：一屏 + 页脚键位行，`空格` 下翻 / `b` 上翻 / `/` 搜索 / `q` 退出；不足一屏或非 TTY 时整段直打）。闸门只留给「没有分页价值、但必须停一下让用户看清」的少量场景：

| 闸门位置 | 理由 |
|---|---|
| `handlers_cache._run_cache_update` | 缓存更新结果摘要（多行统计块，读的是结论不是浏览） |
| `report_artifacts._wait_any_key` | 远程/无图形会话的报告产物清单（无 `y/N` 询问，需先读完路径再重绘） |

其余一律**不设闸门**：面板命令完成、错误提示、取消提示都直接回菜单。

### 分页视图（长输出）

浏览型长输出走 `pager.view`（一屏 + 页脚键位行；不足一屏或非 TTY 整段直打，不多一次击键）：

| 分页位置 | 理由 |
|---|---|
| `handlers_log._cmd_view_logs` | 运行日志详情（最多 200 条，需逐页浏览 + 搜索） |
| `handlers_log._cmd_view_health_history` | 数据源健康历史（最近 10 次，窄档一条占两行） |
| `handlers_log._cmd_run_doctor` | 系统自检结果（逐项 + 修复建议） |

闸门与分页的取舍：**读结论**（统计块、路径清单）用闸门停一下即可；**要浏览**（条目列表、逐项结果）给分页能力。两条清单都由用例与代码调用点比对（`test_prompt_contract`）。

**报告收尾例外（非「按任意键」形态）**：`tui_handlers.finish_report` 在错误摘要与耗时排行之后打印产物清单并问「是否打开报告目录与报告？」——提示用二选一确认 `(y/N)`，**单键读取**（`y`/`Y` = 打开；默认 N，其余任何键含 `n`/回车/`Esc`/未知键都按 N 处理）；`Esc` 只跳过并回菜单（不退出程序），`Ctrl+C` 沿用 TUI 约定退出程序；本地桌面会话才询问 `y/N`；远程 SSH、手机远端、云桌面桥接会话（Catlink / Xpra 类）或无图形界面直接打印清单与传输指引，随后「按任意键返回菜单」——无 `y/N` 询问时由该闸门承担停屏；不发起无效的系统打开动作（Linux 上「有桌面」要求 X socket 真实存在且 `xdg-open` 可执行——tmux/screen 残留的 `DISPLAY` 不算可开）；`xdg-open` 子进程输出丢弃（转发器报错不打乱 TUI 版面）；一次打开失败后本会话直接给路径；非 TTY（脚本/管道）只打印清单、不询问。本地会话的 `(y/N)` 确认与远程会话的「按任意键」闸门同样承担「长输出先读完再重绘」的停屏作用，故不再额外计为停屏步骤。
守护：`test_prompt_contract.py::TestPressAnyKeyGateWhitelist`（新增闸门即失败）。

## Do's and Don'ts — 护栏（与机检同源）

1. **DO** 用数字编号做主入口 · **DON'T** 只给英文首字母（中文标签拿不到助记线索）
2. **DO** 让回车的含义来自提示行标注 · **DON'T** 让回车在不同提示处有时确认、有时取消
3. **DO** 每个面板都支持 `?` · **DON'T** 让帮助只存在于某一个面板
4. **DO** 上屏用用户词 · **DON'T** 把强刷/降级/游标这类内部词直接印给用户
5. **DO** 一次按键给可观察反馈 · **DON'T** 静默吞键（窄屏未登记键也要一行说明）
6. **DO** 长输出后保留「按任意键」 · **DON'T** 每个动作后都加闸门（主路径击键数被放大）
7. **DO** 提示超宽折行 · **DON'T** 假设终端有 100 列
8. **DO** 破坏性操作默认走安全侧 · **DON'T** 让默认项覆盖用户数据
9. **DO** 状态条只讲「正在做什么」（当前阶段/耗时/中止键） · **DON'T** 把已完成的动作塞进状态条（历史流水走落地行，否则用户永远读不到）
