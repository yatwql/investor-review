### P2 — 下一阶段就绪（满足条件即开工）

入选标准：价值明确、成本可控，条件满足即开工。

#### `plan-92` Excel 纯数字呈现，缺可视化辅助

**现状**：19 页签为静态数字与文字，收益率高低、集中度偏离需逐格读数。
**动作**：高价值数值列加色阶/数据条、趋势列加迷你折线（openpyxl 原生）；先试点持仓明细 / 量化指标 / 集中度 2~3 个页签，认可后再扩。

#### `plan-93` 历史报告归档无索引导航

**现状**：HTML 按日期归档到子目录但不生成索引；TUI 无「最近报告」入口；Web 运行历史不含归档目录。
**动作**：生成 / 刷新 `output_dir/index.html`（按日期列出 Excel/HTML 产物与打开链接），TUI 加「打开输出目录 / 最近报告」入口；只列路径信息，匿名化口径与报告一致。

#### `plan-185` 收益率指标缺口径标签，模型反复写错

**现状**：口径标签已落地（`llm/rate_caliber.py` 唯一声明点，并入 `PROMPT_SCHEMA_VERSION` 指纹），**余验收**——事实校验只把数值改对，句意与修饰语仍可能挂错口径。
**验收**：`perf_history.counters.fact_fix_total` 连续若干轮稳定 ≤3 处即归档。

#### `plan-210` 报告重复运行耗时优化（LLM / 新闻当日复用）

**现状**：同一日多次报告（15:57 153s / 16:21 141s）中，`智囊团深度复盘` 71–75s、`新闻获取` 19–23s；LLM 缓存 miss 2/4 与 4/7，专家复盘每轮重算。无 LLM 的报告基线约 44–52s，当前主要增量在 LLM 与新闻。

**动作**：审计专家复盘/健康检查/新闻的缓存键与输入指纹，区分「必须随分钟变化」与「可当日复用」的字段；为专家复盘、新闻抓取与去重建立安全的当日复用；保留持仓/行情/新闻内容变化即失效。先做缓存键审计与基线，再按模块分批启用，避免把陈旧内容缓存进报告。

**不做**：不降低报告事实口径、不缓存跨日行情/新闻、不改变 LLM 模块开关默认值。

**审计结论**：专家复盘/健康检查指纹含 `total_mv` / `total_profit` / `total_today_profit`，行情一变即换键；直接剔除会复用含旧盈亏结论，不能作为安全优化。新闻缓存 TTL 900s、键含 keywords；15:57→16:21 已超 TTL。下一步先做新闻缓存 TTL/命中验证与专家提示词拆分评估，需确认「新闻/盈亏可容忍时效」口径后再改缓存。

**验收**：连续两次同条件报告的第二次 `LLM+新闻` 耗时下降 ≥50%，或专家复盘命中应用缓存；报告内容与首次一致（除生成时间）；补缓存键失效/命中的回归用例。

#### `plan-211` 数据源降级与告警分级（行业资金流向 / hithink / K 线）——进行中

**现状**：行业资金流向连续 5 次报告失败（akshare RemoteDisconnected）；hithink 每轮约 18 条 `Unknown thscode`（如 `561910.SH` / `000925.SH` / `000919.SH`）；腾讯/新浪 K 线风控页每轮 7+7 条 WARNING。熔断与备用链路生效，但报告可能缺数据、日志噪声掩盖真实问题。

**动作**：① 统一数据源不可用/降级的上屏状态，报告显式标注「暂不可用」而非静默省略；② 按资产类型/交易所过滤 hithink 的 A 股价格/历史请求，ETF/场外基金/错误后缀不进入该链路；③ 行业资金流向补备用源或当日缓存；④ 预期风控页/盘后不可用降为 DEBUG 或按源聚合一条摘要。每项独立降级，不改变正常源优先级。

**进展**：K 线风控页逐代码 WARNING 已降为 DEBUG；hithink 已过滤场内 ETF 的 A 股价格/历史槽，并归一 `000925.SH` 类错误交易所后缀；行业资金流向失败类型写回模块状态（连接失败/暂无数据可见）。剩余：行业资金流向备用源/显式状态、同条件报告告警数复测。

**不做**：不伪造数据、不把外部源失败静默当成功；不扩大年报/财报抓取范围。

**验收**：同条件报告 `warnings_count` 从 35 降至 ≤10 且无 `Unknown thscode` 无效请求；行业资金流向有明确可用/不可用状态；补数据源路由与降级回归。
