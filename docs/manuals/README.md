## 怎么读

**首次使用（约 30 分钟走完全流程）**

1. [快速开始](how-to-start.md) —— 装好、放入持仓、生成第一份报告
2. [报告文件结构](reports-instruction.md) §Excel 报告 / §HTML 报告 —— 看懂拿到的东西

4. （可选）[LLM 配置指引](how-to-config-llm.md) —— 想要「全球政经局势 / 智囊团深度复盘」再配

**日常使用（挑一个渠道就够，三渠道共享同一套配置与缓存）**

| 渠道 | 适合 |
|---|---|
| TUI 菜单 | 手机 SSH、偶尔手动跑一次 |
| CLI | 定时任务、脚本化、无人值守 |
| Web | 电脑上想看图、想拖拽上传、想在线改配置 |

**排查与维护**

[数据源一览](datasource.md)（哪个源取什么数据）→ [数据源可靠性](datasource-reliability.md)（降级、熔断、限流）→ [常见问题解答](faq.md) §故障排查 → 跑一次 `doctor`。

## 界面用词对照

程序三个界面（TUI / CLI / Web）刻意使用同一套**用户词**，不用内部工程词。看到这些词时：

| 界面上的词 | 含义 | 代价 |
|---|---|---|
| 用已有结果 | 复用上次 LLM/数据的缓存结果 | 免费，但可能不是最新数据 |
| 重新生成（会调用 AI，计费） | 忽略缓存重新请求 | 会产生 API 费用 |
| 改用备用方案（结果可能略旧） | 首选数据源失败后自动换源 | 数据口径可能滞后一档 |
| 暂时失败，稍后自动重试 | 端点被熔断，冷却后恢复 | 本次可能取不到该数据 |
| 与出厂默认不一致 | 你改过该项配置 | — |

> 报告与 Web 里的「降级」一词专指**数据质量**（某个源没取到、用了更旧的数据），不是端点重试状态。详见 `DESIGN.md` 与 `DESIGN-TUI.md`（设计契约，面向开发者）。

## 本目录的约定

- **命令前缀**：所有 Python 命令一律走项目虚拟环境——Linux/macOS 用 `.venv/bin/python`，Windows 用 `.venv\Scripts\python.exe`；启动脚本（`launch.sh` / `launch.ps1`）会自动准备。
- **路径**：`data/`（你的数据）、`reports/`（报告产物）、`logs/`（日志）都相对项目根目录。详见 [数据与备份](data-and-backup.md) §1。
- **示例持仓**：文中示例代码（如 `600900` 长江电力、`040046` 某基金）仅作格式演示，不是推荐。
- **截图**：截图取自真实运行界面；窄屏/手机端版式与桌面略有差异，面板版式随终端宽度自动分档。
