## 主菜单总览

启动程序后进入 TUI 文本界面主菜单：

```
  ── 生成报告 ──
    [E] 生成基础报告（仅 Excel）
    [B] 生成标准报告（Excel+HTML）
  > [L] 生成完整报告（含 LLM 分析）
    [W] 调仓 What-if 模拟（独立报告）
    [Q] 报告对话式追问
  ── 数据与查看 ──
    [1] 更新基础类缓存
    [2] 更新行情类缓存
    [3] 缓存管理（统计与清理）
  ── 配置 ──
    [C] 配置报告章节显隐
    [S] 配置报告章节内容呈现
    [G] 全局设置
    [R] 刷新配置
  ── 诊断与排查 ──
    [D] 诊断与排查
    [X] 退出（0 亦可）

  ↑↓ 移动 | 回车执行 | 字母/数字键直达 | / 筛选 | Esc / 0 / X 退出 | Ctrl+C 退出
```

### 菜单分组与关键词筛选

主菜单按**任务域**分四组渲染——`生成报告` / `数据与查看` / `配置` / `诊断与排查`，退出项单列在末尾。组标题只为降低扫读成本，**不改任何按键**（组内仍是原来的字母/数字直达键与方向键导航）。

各组成员：「生成报告」E/B/L/W；「数据与查看」Q/1/2/3（报告追问 + 缓存更新/清理）；「配置」P/S/M/I/A/D/R（报告章节、功能开关、LLM 多链、对比指数、匿名化、目录与文件名/输出目录、刷新配置）；「诊断与排查」V/H/T。

菜单项多时按 `/` 直接搜：

```
  筛选关键词（空=显示全部 · Esc 取消）: 缓存
```

- 命中规则：先比按键（输入 `T` 即 `[T] 系统自检`），再比标签文字（输入 `缓存` 命中三处缓存项）；
- 筛选后菜单只显示命中项与命中分组，`↑` `↓` 在命中项之间循环；
- 筛选态下按到被隐藏项的键，会提示「不在当前筛选结果中」而不是静默无反应；
- `0` **先清除筛选**（无筛选时才是退出），`X` / `Esc` 始终可直接退出；`/` 再输一次可换关键词。

> **启动后缺省选中 `[L]`（生成完整报告）**——初始光标由 `config.json` 的 `default_menu_key` 决定（出厂值 `"L"`，取值为任一菜单快捷键），取值未命中时回落到首项 `[E]`；上方示例即缺省状态下的实际呈现。修改方式见[配置指南](how-to-config.md)。
>
> **[T] 系统自检恒上屏**（无功能开关）——它是只读诊断，不改报告产物、不写文件。菜单项常驻，`doctor` 子命令同源可用；不需要看它时忽略即可，无需也不能在 `[S]` 中关闭。
>
> **[Q] 报告对话式追问按开关显示**（开关 `report_qa`，实验项默认关）——关闭时 [Q] 与 [T] 同机制整体裁剪；开启方式：**[S]** 面板「报告对话式追问」条目（或 `--experiment report_qa`）。回答基于报告生成时的数据（非实时），仅供参考，不构成操作建议；用量独立记账，不计入报告 LLM 用量页签。

### 键盘操作

| 操作 | 说明 |
|------|------|
| **↑ ↓** | 方向键上下移动选择项（全档可用；主菜单原地刷新不滚屏，全部列表面板 `[C]/[A]/[D]/[I]/[S]/[M]` 内移动 `▸` 选中、回车按选中项派发） |
| **回车** | 执行提示行标注的默认项（主菜单按选中项执行；`[S]` 面板按 `▸` 选中项切换；各处提示都会写明回车具体做什么） |
| **?** | 帮助：面板内输入 `?` 看本面板可用键与作用，`?3` 看第 3 项说明（全角 `？` 同效；详情由各面板提供，如 `[M]` 显示模型与优先级、`[A]` 说明模式切换效果） |
| **字母/数字键** | 快捷键直达功能（未登记的键无反应） |
| **Esc** | 主菜单：**连按两次**退出（3 秒窗口内，首按给确认提示——防高延迟链路上方向键拆包误判为退出）；子菜单：返回上一步（**所有选择类提示**——y/N 确认、级别筛选、日期/编号录入——按 Esc 即时取消返回主菜单，无需找「0 返回」；长文本提问用 `q`/回车取消；生成一旦开始请等其完成，勿在运行中强行中止） |
| **0** | 退出程序（与 `[X]` 等价；子菜单里 `0` 是「返回」，首页返回即退出） |
| **Ctrl+C** | 退出程序 |

> 方向键在 SSH / tmux 下可能无效，可使用字母/数字快捷键替代。
>
> **窄屏（手机竖屏，<64 列）直达与导航并存**：按上表的字母/数字键即直达执行（主路径，未登记键无反应）；方向键同样可用——移动选中光标后菜单**原地刷新**（不滚屏），Enter 执行当前项。

## 各菜单项详解

### 报告生成类

> **生成完成后**：程序打印耗时排行与**本次产物清单**（报告目录 + 已生成的 HTML / Excel），随后问一句「是否打开报告目录与报告？(y/N)」——按 `y`/`Y` 打开（目录与报告一起开），**直接回车或按其它任意键 = 不打开**（默认 N），按 `Esc` 同样只是跳过并回主菜单。没有图形界面（或 `xdg-open` 不可用）时不会报错，改为提示手动访问上方路径。

#### [E] 生成基础报告（仅 Excel）

读取持仓 → 获取行情 → 生成 Excel 报告，默认包含 7 个核心页签：
- 投资分析汇总、持仓明细与分类、资产穿透 TOP10、基金业绩分析、组合演进、数据源可用性矩阵

其中组合演进章节由配置项 `enable_portfolio_evolution` 控制（默认开启，可在菜单 `C` 切换）。行动建议章节由 `enable_action` 控制（默认开启，可在菜单 `C` 关闭，开启后 E/B/L 均输出）。无新闻、无 LLM、无基金深度分析。生成速度最快，适合快速查看持仓概况。

#### [B] 生成标准报告（Excel+HTML，按章节配置）

在 E 的基础上增加：
- **财经新闻** — 5 源并行获取，与持仓关键词关联匹配
- **组合历史走势与回撤** — 视 `history.fetch_mode` 配置而定
- **基金深度分析** — 持仓结构与集中度、风格与因子分析（+「基金业绩分析」章末尾的基金经理变更监控块）
- **环比摘要/快照对比** — 与上次报告自动对比

不含 LLM 分析。

#### [L] 生成完整报告（Excel+HTML，含 LLM）

全功能报告，在 B 的基础上增加：
- **LLM 多模块分析** — 全球政经局势、智囊团深度复盘、持仓体检报告、穿透深度分析、新闻关联分析（可选）
- **行业资金流向** — 注入实时行业资金流数据
- **LLM API 用量页签** — Token 消耗统计、费用估算
- **单屏一次确认** — 生成前先上屏本次 LLM 费用区间与今日已花费/日预算，随后**一个问句 + 一行按键**即定：问句直接说明代价差异（「是否用已有的 AI 分析结果生成？（`Y`=用已有结果，免费但可能不是最新；`N`=重新生成，会产生费用）」），按键行作答——回车或 `Y` = 用已有结果生成（默认）/ `N` = 重新生成（再选模块，`f` 为同义键）/ `q` = 中止（`history.fetch_mode` 为 `prompt` 时多一个 `h` = 含历史走势；`auto`/`off` 模式历史走势按配置自动决定、不另问）；今日超日预算（`daily_cost_limit`）时改问「用已有结果继续 / 中止」安全网，该路径会清空本次重新生成范围；`prompt` 模式该路径会提示「本次用已有结果，不获取历史走势」（告知后覆盖，不追加提问）

> **建议使用顺序**：按菜单 L 生成全量报告（含 LLM），如需单独生成不含 LLM 的版本可随后执行 B 或 E，程序会复用已缓存的行情和新闻数据。
>
> **模块级重新生成**：上面问句答 `f`（重新生成），会追加一步**模块多选**——列出可重生成的模块（全球政经局势 / 智囊团深度复盘 / 持仓体检报告 / 穿透深度分析 / 财经新闻关联 / 生成后自检 / 持仓变动复盘归因），可输入编号或键名（逗号/空格分隔，支持子集），**直接回车 = 全部模块**。仅指定模块会绕过已有结果重新生成，其余照常命中缓存——对某个模块的输出不满意时可单独重跑，不必全量烧钱；未识别的输入会告警并按全部模块重生成。

#### [W] 调仓 What-if 模拟（对比两份持仓，独立报告）

对比**基准持仓（调仓前）**与**目标持仓（调仓后/假设）**两份持仓文件，生成独立调仓 diff 报告（不并入主报告管线）：
1. **选择基准持仓**（调仓前）— 默认使用当前配置的持仓文件，或从目录中挑选
2. **选择目标持仓**（调仓后/假设）— 从持仓目录中挑选基准之外的另一份 xlsx 文件；若目录只有基准一份，引导选择：`[1]` 自动复制基准为可编辑模板（生成 `<基准名>-调仓后模板.xlsx`，改份额后再运行）/ `[2]` 手动输入目标文件完整路径
3. **输入调仓生效日（可选）**— 直接回车跳过则仅做成本口径截面比较（格式非法会提示并重新询问）；输入 `YYYY-MM-DD`（如 `2026-07-01`）则 opt-in 联网取生效日后行情，追加**时序回测**（区间/年化收益、波动率、夏普、最大回撤）
4. 程序输出 **Excel**（调仓摘要 / 分类配置对比 / 持仓变动明细 3 页签 + 指定生效日时第 4 页签「时序回测」）+ **HTML**（双栏对比 + 资产配置双环图 + 回测折线图）

产物输出到报告输出目录：最新版固定名 `调仓模拟.xlsx/.html`（每次覆盖为最新对比），历史归档至 `YYYYMMDD/` 日期子目录（超 180 天自动清理），独立输出不影响主报告。默认**本地计算**；申购受限提示经缓存链读限购总表（命中缓存零联网、未命中现场取一次、失败静默无提示）；仅指定生效日时联网取历史。

> **设计边界**：What-if 模拟为**成本口径**截面比较（份额 × 每份成本）；指定生效日启用时序回测为**假设推演、不构成收益承诺**，数据不足时回测降级不阻塞主报告。详见[报告说明](reports-instruction.md#调仓-what-if-模拟独立报告)。

### 对话式追问类

#### [Q] 报告对话式追问（对已生成 HTML 报告多轮提问 · `report_qa` 实验项，默认关闭）

对**已生成的 HTML 报告**发起多轮追问：从报告输出目录选择一份报告，进入文本输入循环（提问 → 展示回答 → 续问），会话保留上下文。

**操作流程**：
1. 主菜单按 `Q`（`report_qa` 开关未开时菜单项不出现）；
2. 选择报告：列出输出目录下的 HTML 报告（按修改时间倒序，最多 8 份；回车 = 最新，`q` 取消；无报告时提示先生成）；
3. 输入问题回车 → 等待回答 → 继续提问；输入回车或 `q` 返回主菜单。

**要点**：
- 与 Web 报告页问答、报告「报告问答（⚗ 实验）」区块**同一个会话服务**（`qa/session.py`）：路由/上下文提取/事实核对/降级全部同源，无 TUI 私有副本；
- 每份报告一个会话：首次提问创建、后续续用；达到轮数上限（10 次提问）后自动开新会话（提示后返回主菜单，重新进入可继续）；
- 用量独立记账（不进报告 LLM 用量页签）；联网核对与 Web 同口径（`qa_fact_check` 关 / 无 Tavily key 时自动跳过并提示「未执行联网事实核对」）；
- 回答基于该报告生成时的数据（**非实时**），仅供参考，不构成操作建议。

### 配置管理类

#### [C] 配置报告章节显隐（16 项四块 + 智囊团两个子项）

交互式配置**报告章节是否出现**。清单、编号与分块由章节注册表（`config/chapter_registry.py`）派生，四块共 16 项，编号连续（1-16）；第 7 项「智囊团深度复盘」下的 `7.1` / `7.2` 是其**生成选项**，不占章节编号：

```text
  ── 顶层章节 ──
   1. 基金深度分析            enable_fund_deep_analysis  [开启]
   ...
  ── LLM 章节 ──
   7. 智囊团深度复盘          expert_review              [开启]
      7.1 辩论-正反辩论        llm_debate_procon          [关闭]
      7.2 辩论-条件推理        llm_debate_conditional     [开启]
  ── 默认关闭的整章 ──
  13. 调仓纪律回放            rebalance_schedule_replay  [开启]
  ── 关联产物 ──
  16. What-if 交易成本对比    whatif_trade_cost          [关闭]（仅调仓模拟报告）
```

**顶层章节（1-5，写 `config.json`）**：

| 编号 | 章节 | 键名 |
|:----:|:-----|:-----|
| 1 | 基金深度分析（持仓结构与集中度 / 风格与因子分析 + 基金经理变更监控块） | `enable_fund_deep_analysis` |
| 2 | 市场新闻（财经新闻热点与持仓关联分析） | `enable_news` |
| 3 | 组合历史走势+回撤（走势表 + 回撤矩阵 + 危机区间标注） | `enable_history` |
| 4 | 组合演进（多快照趋势） | `enable_portfolio_evolution` |
| 5 | 行动建议（再平衡信号 / 交易纪律 / 调仓建议 / 收益归因） | `enable_action` |

**LLM 章节（6-12，写 `llm_settings.json` 的 `enabled_llm`）**：

| 编号 | 章节 | 键名 |
|:----:|:-----|:-----|
| 6 | 全球政经局势 | `global_macro` |
| 7 | 智囊团深度复盘 | `expert_review` |
| 7.1 | 辩论-正反辩论（三段式：白脸→黑脸→综合；默认关） | `llm_debate_procon` |
| 7.2 | 辩论-条件推理（情景化分析：涨/跌/震荡；默认开） | `llm_debate_conditional` |
| 8 | 财经新闻热点与持仓关联分析 | `news_correlation` |
| 9 | 持仓体检报告 | `health_check` |

要点：

- **只切显隐**：章节集合与顺序由注册表和 `report_section_order` 决定，面板不增删章节、不改顺序；关闭后该章完全隐藏，其余章节自动连续编号。

- **子项闸门**：`7.1` / `7.2` 只在智囊团开启时可切换；关闭时子项置灰并提示「启用本章节后可切换」。
- **稳定入口是键名**：编号随注册表顺序派生，`?键名` 查询不受编号漂移影响；行尾 `*` 表示当前值与出厂默认不一致。
- **LLM 章节行尾费用摘要**：近 7 日该模块调用次数 / 累计费用 / 单次均值（读取失败静默省略）。

> **各组与实验身份**：六组按「报告里在哪看」（**作用域**）划分——持仓与交易 / 市场与估值 / 基金与风格 / 事件与摘要四组只在既有章节内追加内容块、列或子表；呈现与交互只改呈现与追问入口；机制与质量是提示词注入与输出评级。**实验身份是另一根轴**（`experimental` 字段，行首 ⚗ 标记）：实验项开启会改变产物、随产物自述，`--experiment` 取值域与页脚自述也只认它。**转正**（某项验证通过）= 摘除 experimental 身份（⚗ 消失、不再随产物自述），作用域不变则原地留块、作用域变化才改组；面板编号由组序 + 注册表声明顺序派生，转正不承诺跨块位移，面板入口随之延续。

##### [G] → [M] LLM 多链线路优先级（备用顺序）

多链（Multi-Provider Chain）按 `llm_providers.json → providers[].priority` 排定备用顺序（数值小 = 链序靠前）。面板按当前顺序列出线路，输入**两个编号**交换位置（如 `3 1`）即写盘——写前自动 `.bak` 备份、注释保留；`Esc` 即时返回主菜单，仅一条线路时显示「无需调整」。互换写盘后**立即生效**：页头状态行 `LLM ●` 后显示当前链首线路名，回首页即见新顺序，同会话下一次生成也用新链序（无需重启；手工改优先级同效，按 `R` 亦可全量重读）。当前策略为 `weighted`/`cost_first` 时实际链序由权重/成本决定，此顺序仅在 `priority`/`fallback_only` 策略下生效（面板会提示，状态行此时不显示链首）。同步入口：CLI `--llm-provider-order`、Web 配置面板（见 how-to-config-llm.md）。

##### [G] → [I] 对比指数池

交互式维护竞争语境对比指数池。可添加/删除指数代码，用于报告中组合与基准的多维度对比（收益、夏普、波动率、最大回撤）。默认预设池为沪深300 + 中证500 + 中证全债，无需手动维护即可获得有意义的对比。

##### [G] → [A] 持仓匿名化（代码/名称脱敏）

交互式设置持仓匿名化模式。支持 4 种模式：
- **关闭** — 显示真实名称和代码（默认）
- **代码显示** — 名称替换为「品种X」，保留证券代码和盈亏数据
- **完全匿名** — 名称→"品种X"，代码→"000XXX"，盈亏→±XX%
- **汇总模式** — 仅显示大类汇总，不展示单品种明细

选择后立即保存到 `config.json` 的 `anonymization.mode`。匿名化仅在报告生成阶段生效，不修改原始持仓文件。

- **[F] 持仓信息文件名** — 修改要读取的持仓文件名（配合 [C] 使用）。
- **[M] 配置入口地图** — 只读索引：列出「功能开关 / LLM 模块启停、报告章节取舍、对比指数池、匿名化、配置与目录、刷新配置、缓存管理、健康历史与日志、系统自检」各自在哪个菜单键下，新用户不必逐面板试。**不修改任何配置**，仅导流。
- **[L] LLM 调优参数** — 调 `llm_settings.json` 的几个运行参数：thinking 模块并发上限（默认 2；端点偶发空内容时改回 1）、LLM 模块并发线程数（默认 3）、单请求重试次数、整链失败重试等待、LLM 总时间预算、日费用上限。取值范围与说明由共享白名单下发（与 Web 配置面板同一份），超范围会明确拒绝；改完即时生效（无需重启）。
- **[O] 报告输出目录** — 修改报告输出目录（默认 `reports/`）。每次生成同时保留两份：
- **最新版** — `个人投资分析报告.xlsx` / `个人投资分析报告.html`（覆盖写入）
- **归档版** — `个人投资分析报告-YYYYMMDD-HHMMSS.xlsx` / `.html`（按日期命名）

> 程序自动清理 180 天前的归档目录，如需长期保留请移出 `reports/`。

> **P 与 S 的分工（配置入口边界）**：TUI 的配置入口按「**改了会怎样**」划分，同一件事不会两处可改：
>
> | 菜单 | 面板标题 | 管什么 | 存放 |
> |:--|:--|:--|:--|
> | `[C]` | 报告章节显隐 | **16 项四块**：顶层章节 5 / LLM 章节 7（含 `7.1`/`7.2` 生成选项）/ 默认关闭的整章 3 / 关联产物 1 | `config.json` 的 `enable_*`、`llm_settings.json` 的 `enabled_llm`、`features.json` |
> | `[S]` | 报告章节内容呈现 | **20 项六组章内内容**：持仓与交易 4 / 市场与估值 4 / 基金与风格 3 / 事件与摘要 4 / 呈现与交互 2 / 机制与质量 3 | `features.json` |
>
> 简记：**`[C]` = 哪些章出现（顶层 / LLM / 整章 / 关联产物）；`[S]` = 章内多出什么内容**。
> 报告增强子模块（数据质量仪表盘 / 市场温度 / 行业Beta子表 / 候选基金比较 / 成本流水 / 估值分位）在 `[S]` 的对应内容组；独立整章（调仓纪律回放 / 持仓变动复盘 / 个股基本面）与关联产物在 `[C]`；两个面板下方互相给出跳转提示。

#### [R] 刷新配置

重新加载 `config.json` 与 LLM 三文件合并配置（`llm_settings.json` / `llm_key.json` / `llm_providers.json`），立即生效无需重启程序（页头状态行同步重绘）。手工修改任一 LLM 配置文件后其实无需按 `R`——下一次读取自动重读；`R` 提供确定性的全量重入口。

### 缓存管理类

#### [1] 更新基础类缓存

清除并重新获取（`clear_by_group("refresh")` 先清后取，覆盖 18 个数据模块）：基金业绩、持仓明细、基准、行业分类、新闻、盈利预测、行业资金流向、分红、基金经理、基金风格扩展、市场情绪、财报索引/正文、财务指标、申赎费率、无风险利率、指数估值历史。

**附带清除**：财经新闻热点与持仓关联分析（LLM 缓存）。

纯股票组合时自动跳过基金相关刷新（基金业绩/持仓/基准/基金经理），但仍主动重拉行业分类、分红、盈利预测、资金流向，并刷新财经新闻与基金风格扩展缓存。

#### [2] 更新行情类缓存（含价格/指数等）

清除并重新获取：价格行情、指数行情。

**附带清除** LLM 缓存（`clear_by_group("preload")` 先清后取）：智囊团深度复盘、全球政经局势、持仓体检报告、穿透深度分析、生成后自检、持仓变动复盘归因（另含辩论三段缓存 `llm_debate_*`，其登记在缓存域）。

适合：切换到另一份持仓文件时，一键清理依赖旧持仓的缓存。

#### [3] 缓存管理（统计与清理）

合并原「清理」与「统计」两个平级入口为一个子菜单，动线**先统计后清理**——进入即见统计（想清理前先看规模），随后按命令行操作：

- **3 清理过期缓存**：按 TTL 扫描删除已过期的缓存文件（不影响未过期项）；执行完按任意键**回到统计**刷新展示
- **0 返回主菜单**（回车同效）

统计为**只读浏览，不执行删除操作**。分三块展示：

**data/cache/**（API 响应缓存）：
- 文件总数 / 总大小
- 命中率统计
- 按前缀分类统计
- 最大文件 TOP3
- 过期文件数预览（子菜单内输入 3 清理）

**data/history/snapshots/**（持仓快照）：
- 快照文件数 / 总大小
- 最新快照时间
- 超期自动删除，不随缓存清理

**data/state/**（运行时状态文件）：
- 状态文件数 / 总大小
- 跨会话持久化，不随缓存清理

### 诊断与排查类

#### [D] 诊断与排查（L/V/H/T，缺省选中系统自检）

`L` 日志设置 / `V` 运行日志 / `H` 健康历史 / `T` 系统自检；回车直接执行系统自检，`0` 返回主菜单。


##### [D] → [V] 运行日志（可按级别筛选）

读取 `logs/app.log`，按时间戳切分记录并以 `time [LEVEL] message` 展示；多行正文（如 traceback）归并缩进展示。仅浏览，不修改任何数据。

- 按级别筛选：ERROR 红 / WARNING 黄着色（NO_COLOR 或非终端环境自动降级为无着色）
- traceback 折叠为「⤷ 堆栈详情 +N 行」，按需展开
- 默认读取末尾 200 行；不适合交互式手工翻看超大日志（大文件反向分块读取不卡顿）

##### [D] → [H] 数据源健康历史

聚合 `data/state/datasource_health.jsonl` 最近若干次运行的健康检查结果，展示 ok/total 与失败源清单。配合菜单 `D` → `V` 在数据源异常时快速定位。

##### [D] → [T] 系统自检（环境/配置/目录/数据源一键体检）

> **恒出现在主菜单中**（无功能开关，不可关闭）。`doctor` 子命令同源可用。

一键盘点运行环境，按 **环境 / 配置 / 目录 / 日志与缓存 / 功能开关 / 数据源适配 / 数据源凭据 / 数据源** 八组输出检查结果：通过项标 `[OK]`、失败项标 `[!]` 并**附可执行修复建议**（如「改用 `.venv/bin/python`」「建目录或改 `config.json`」）。适合新机部署、报告跑不起来、怀疑配置损坏时先跑一遍。

- **纯只读诊断**：写探测用于判断目录可写性，哨兵文件**即刻删除**；不改任何配置或缓存
- **自身永不抛异常**：任一项出错都转成该组的一条失败结果行——配置损坏正是它要诊断的场景，此处崩掉等于在最需要它的时刻失效
- **零重依赖**：不依赖 pandas（其缺失正是它要报告的一类失败），故即使环境残缺也能跑起来
- 同一条链路在 CLI 侧为 `doctor` 子命令（**不受开关约束**，始终可用）、Web 侧为运行状态区「系统自检」卡片

## 持仓快照自动清理

B/L 菜单生成报告时自动保存持仓快照（环比对比用），并清理超过 180 天的旧快照（保留天数可通过 `config.json` 的 `history.snapshot_retention_days` 配置），避免 `data/history/snapshots/` 目录无限堆积。

## 生成报告建议顺序

1. **首次使用** — 确保持仓文件就绪后，直接按菜单 **L**（全量报告，含 LLM）
2. **日常更新** — 菜单 **`[1]`** 更新基础缓存 → 菜单 **B** 生成含新闻的报告
3. **需最新行情** — 菜单 **`[2]`** 更新持仓缓存 → 菜单 **L** 生成完整报告
4. **仅看概览** — 菜单 **E** 快速生成基础 Excel 报告
