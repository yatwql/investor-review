映射规则（v1 → v2）

v1 键v2 位置说明
temperature_<模块> 等 6 项modules.<模块>.<参数>模型/温度/长度/超时/简报/提示词
cache_enabled_<模块>modules.<模块>.cache短名，段内已表达归属
thinking_enabled/budget/reasoning_effort_<模块>modules.<模块>.thinking.{enabled,budget,effort}三者同属一个业务概念
enabled_llm.<模块>modules.<模块>.enabled启停与参数同段
llm_max_thinking_concurrency 等 6 项runtime.*对应面板「LLM 调优参数」组
debate / fact_check / pricing / news_correlation_top_nadvanced.*高级选项（避免与 features.json 同名）

代码侧改动面

get_llm_config() 仍返回扁平视图，因此 llm/ 包 0 改动（实测 116 处逐键读取、18 处按 suffix 拼键全部不动）。

要改的只有 4 处：config/_llm_settings.py（v1/v2 判定 + 展平/反展平）、_llm_settings_defaults.py（模板）、core/data_registry.py（结构校验）、config/edit_ops.py（调优项写入路径）。

缺省继承（三层，确定性）

模块值 → defaults → 代码内置默认。

defaults 初值取程序内置默认，不做众数推断；迁移后用户可把共识值手工上提到 defaults。

当前 defaults 推导值：
{"model": null, "temperature": 0.3, "max_tokens": 3072, "timeout": 60, "cache_enabled": true, "output_brief": false, "system_prompt": null, "thinking_enabled": false, "thinking_budget": 6000, "reasoning_effort": "high"}

运行约束段（＝面板「LLM 调优参数」）

{"max_concurrency": 3, "thinking_concurrency": 2, "max_retries": 2, "full_fail_retry_delay_sec": 30, "time_budget_sec": 0, "daily_cost_limit": 0}

面板上 6 个调优项的标签与范围不变，只是落盘位置从顶层变成 runtime.*。

迁移与回滚

v1 文件照常读；首次写入落为 v2，写前 .bak。

回滚 = 还原 .bak（程序同时支持读 v1）；doctor 增「结构版本」项。
