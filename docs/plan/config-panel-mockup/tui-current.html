  ── 生成报告 ──
  > [E] 生成基础报告（仅 Excel）
    [B] 生成标准报告（Excel+HTML，按章节配置）
    [L] 生成完整报告（Excel+HTML，含 LLM）
    [W] 调仓 What-if 模拟（对比两份持仓，独立报告）
  ── 数据与查看 ──
    [Q] 报告对话式追问（对已生成 HTML 报告多轮提问）
    [1] 更新基础类缓存（含基金业绩/持仓/经理/基准等）
    [2] 更新行情类缓存（含价格/指数等）
    [3] 缓存管理（统计与清理）
  ── 配置 ──
    [P] 配置报告可选章节（顺序与取舍）
    [S] 配置功能开关（作用域四组，含 LLM 章节）
    [M] 配置 LLM 多链线路优先级（备用顺序）
    [I] 管理对比指数池（自定义基准指数）
    [A] 配置持仓匿名化（代码/名称脱敏）
    [D] 查看配置与目录信息（持仓目录/文件名/输出目录）
    [R] 刷新配置
  ── 诊断与排查 ──
    [V] 查看最近运行日志（可按级别筛选）
    [H] 查看数据源健康历史
    [T] 系统自检（环境/配置/目录/数据源一键体检）
    [X] 退出（0 亦可）
