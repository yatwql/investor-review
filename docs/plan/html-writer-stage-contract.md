# HTML 报告装配拆分 —— 结构契约（plan-248）

> 状态：**已完成**（契约用例 + 两批实施；结果见 §8）
> 对象：`src/python/report/html_writer.py::write_html_report`（397 行）
> 关联：`plan.md` → `plan-248`；契约由新建结构用例与既有集成/场景用例共同守护

## 1. 立项背景

单函数承担四类职责：① 19 个章节区块的数据装配（每个 `_render_*` 返回元组再解包）；② 模板变量绑定；③ 渲染后的三步后处理（资产内嵌 / 匿名化 / 落盘）；④ 阶段计时（4 个 `_mark`）与降级告警。

体量本身不是主要问题——**问题是「区块装配顺序」与「章节顺序」的对应关系只存在于函数体的调用顺序里**：调整章节顺序、或新增一个区块，只能在 400 行里找位置，没有结构化信号，也没有任何断言能在顺序被改坏时响。

## 3. 结构契约（拆分必须保持）

| # | 契约 | 违反后果 | 守护方式 |
|---|---|---|---|
| 区块顺序 | **章节装配顺序 = 报告目录顺序**，且顺序以显式有序结构（如 `_SECTION_BUILDERS` 元组）表达，而非散落在语句顺序里 | 目录与正文错位，读者按目录跳错章 | 新增结构用例：有序表逐项名与实调顺序一致 |
| 区块返回值 | 每个装配函数返回的**元组形状**与其消费点一一对应（解包位数/字段语义不变） | 解包错位 → 变量串位（市值被当盈亏渲染） | 既有集成用例（章序/一致性）+ 装配函数单测 |
| 阶段名集合 | 阶段名集合固定：`模板渲染` / `资产内嵌` / `匿名化` / `落盘` | perf 历史断档，跨版本耗时不可比 | perf 记录断言（阶段名集合相等，不做计数写死） |
| 匿名化时序 | 匿名化在**渲染之后、落盘之前**，模式判定单点（`get_anonymization_mode`） | 脱敏泄漏（正文含真实姓名/账号）或脱敏后模板失效 | `scenario/security` 用例（现有） |
| 原子落盘 | 落盘走 `core.atomic_write` 原子写，失败不留半份文件 | 半份 HTML 被浏览器打开即空页 | 原子写单测 + 落盘失败路径用例 |
| 渲染异常隔离 | 渲染期异常隔离：单区块装配失败退化占位而非整份失败 | 单章数据缺失导致整份报告不可用 | `integration/test_error_isolation.py`（现有） |

## 4. 拆分方案（目标形态）

- `html_writer.py` 保留 `write_html_report` 作为**编排壳**（阶段 ②③④ + 顺序表遍历）；
  **形态目标已按实测调整**：编排壳不以行数为目标，而以「装配与后处理各自成表」为准——
  壳内剩下的模板参数是**显式绑定**（`_render_template(...)` 逐个 `name=value`），
  它是「产物→模板变量」这层契约的可见面，压成 dict 只会多一层间接；
- 阶段 ① 的装配按主题拆到 `html_sections_*.py`（持仓/指数行业/基金深度/新闻与 LLM 四组），每组导出其装配函数与被顺序表引用的名字；
- 顺序表 + 模板变量映射表成为**单一事实位**（新增区块只改这两处）。

## 5. 验收口径

1. 结构用例：顺序表 ↔ 实调顺序一致；阶段名集合相等；
2. 既有 `integration/`（章序一致性、错误隔离）与 `scenario/`（security、pipeline）全绿；
3. 形态验收改为：装配（`SECTION_BUILDERS`）与后处理（`HTML_POST_STAGES`）各自成表、
   产物经 `SectionBindings` 具名返回；`write_html_report` 只剩「上下文装配 → 按表执行 →
   模板参数显式绑定 → 返回路径」（实测 265 行，其中约 110 行为模板参数绑定）；
4. 生成一份真实报告，逐章与拆分前 diff 为空（HTML 文本级对比，排除时间戳/随机 ID）。

## 6. 风险与回滚

- 风险最高处：「区块返回值」的元组解包错位（静默串位）。缓解：先加结构用例与逐章 diff 脚本，再动代码；每次只搬一组区块。
- 回滚粒度：按「主题组」提交（4 次），任一失败只回滚该组。

## 7. 非目标

- 不改模板本身、不改章节内容与文案；
- 不重构各 `_render_*` 的内部实现（仅移动位置与显式化顺序）；
- 不动 Excel 侧（另一条线）。

### 实施结束时的形态偏离（记录在案）

参数绑定（约 110 行）。判定：**接受偏离，不继续压行**——理由是
